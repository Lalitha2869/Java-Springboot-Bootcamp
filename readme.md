# Java Bootcamp 🚀

A hands-on Java learning journey covering core Java, OOP, collections, exception handling, and practical console applications.

## Day 1 – Java Basics

Topics covered:
- Java setup and execution
- Variables and data types
- Operators
- if-else and loops
- break and continue
- FizzBuzz
- Even/Odd program
- `javac` and `java`

## Day 2 – Methods, Arrays & Strings

Topics covered:
- Methods and parameters
- Return values
- Method overloading
- Arrays
- ArrayList
- String methods
- String immutability
- StringBuilder

Practice Programs:
- Student Marks Analyzer
- Employee Salary Analyzer
- String Analyzer

## Day 3 – OOP Fundamentals

Topics covered:
- Classes and Objects
- Constructors
- `this` and `super`
- Encapsulation
- Getters and Setters
- Inheritance
- Method Overriding
- Polymorphism
- Abstract Classes
- Interfaces

Practice Tasks:
- Book class with constructor, getters/setters and `toString()`
- Person, Student and Teacher using inheritance and polymorphism

## Day 4 – Collections, Exceptions & Capstone

Topics covered:
- Collections
- List, Set and Map
- ArrayList and HashMap
- Generics
- Optional
- Exception handling
- Custom Exceptions
- Lambda expressions
- Streams
- Filtering and Sorting

Capstone:
- Console Book Manager
- Add books
- List books
- Search/lookup books
- Delete books
- Handle missing books
- Handle invalid input
- Custom `BookNotFoundException`

## Tech Stack

- Java
- Maven
- IntelliJ IDEA
- Git & GitHub
